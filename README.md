# FinTrack Pro — Corporate Payroll & Salary Management System

একটি সম্পূর্ণ ও প্রফেশনাল এমপ্লয়ি স্যালারি ও পে-রোল ম্যানেজমেন্ট সিস্টেম (PF এবং ESI ব্যতীত)।

## 🌟 প্রধান সুবিধাসমূহ:
- **PF & ESI বাদ দিয়ে কাস্টম স্যালারি কাঠামো:** Basic, House Rent, Medical, Conveyance, Bonus, Overtime এবং বিভিন্ন কর্তন সমন্বয়।
- **মাসিক পে-রোল প্রসেসিং:** উপস্থিতি, অনুপস্থিতি, বোনাস এবং ওভারটাইম ভিত্তিক স্বয়ংক্রিয় হিসাব।
- **অফিসিয়াল স্যালারি স্লিপ (Payslip Voucher):** প্রিন্ট ও পিডিএফ উপযোগী ভাউচার (বাংলা ও ইংরেজি সংখ্যা ও কথায় রূপান্তর)।
- **মাস্টার স্যালারি রেজিস্টার:** সম্পূর্ণ বিস্তারিত কলাম শিট ও CSV এক্সপোর্ট।
- **ব্যাংক ট্রান্সফার অ্যাডভাইস লেটার:** ব্যাংক ম্যানেজারের কাছে জমা দেওয়ার ফর্মাল লেটার।
- **অগ্রিম বেতন ও লোন লেজার:** অগ্রিম বেতন দেওয়া ও মাসিক স্যালারি থেকে কিস্তি কর্তন।

## 🚀 লোকাল মেশিনে রান করার নিয়ম:

1. রিপোজিটরি ক্লোন করুন:
```bash
git clone <YOUR_GITHUB_REPO_URL>
cd <repo-name>
```

2. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

3. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

4. প্রডাকশন বিল্ড ও রান:
```bash
npm run build
npm start
```
